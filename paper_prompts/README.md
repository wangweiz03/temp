# Paper prompt transcriptions

This directory contains non-runtime prompt transcriptions from Tables 17 and 18 of the accompanying MetaMLE paper. The prompt listings use plain-text files and are not imported by the ERS runtime. Text represented by an explicit “omitted for brevity” placeholder in the paper is not reconstructed or invented here.

The baseline system instructions from Table 17 are also defined as `SYSTEM_PROMPT` in `prompts.py`. The task-level Skill example from Table 19 is `skills/SKILL_mlsp-2013-birds.md`. The failure-prevention Skill corresponding to Table 20 is `skills/SKILL_error.md`.
